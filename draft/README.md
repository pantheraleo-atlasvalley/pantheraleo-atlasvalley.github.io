- Versione di lavoro: `Atlas Valley Yield Lab v0.1.1` (`AV01.000`).
- Modifiche maggiori dall’ultima versione: **9 / 100**. I dettagli sono registrati in [CHANGELOG.md](CHANGELOG.md).
